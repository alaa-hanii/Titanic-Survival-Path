# 🚢 Titanic-Survival-Path

### AI-Based Ship Navigation Using Search Algorithms

##  Overview

Titanic Pathfinder is an Artificial Intelligence course project that simulates a ship navigating through an ocean environment filled with obstacles.

The project focuses on applying AI search algorithms to find safe and efficient paths from a starting point to a target destination while avoiding obstacles such as icebergs.

##  Project Objectives

- Implement different AI search algorithms.
- Visualize how search algorithms explore possible paths.
- Find safe routes while avoiding obstacles.
- Compare the performance of different search strategies.
- Understand the differences between uninformed and informed search algorithms.

##  Search Algorithms

The project will explore and implement the following algorithms:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Depth-Limited Search (DLS)
- Uniform Cost Search (UCS)
- Greedy
- A* Search

##  Simulation Environment

The simulation will include:

- **Ship:** The starting position.
- **Destination:** The target location.
- **Ocean:** Navigable cells.
- **Icebergs:** Obstacles that block movement.
- **Danger Zones:** Cells with higher movement costs (planned).
